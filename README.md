# LMS–ERP Integration Platform

## Overview

The LMS–ERP Integration Platform is a web-based application designed to integrate a custom-built Enterprise Resource Planning (ERP) system with Moodle Learning Management System (LMS). The platform automates synchronization of students, faculty, courses, enrollments, attendance, and grades using Moodle REST APIs.

## Features

- Student Management
- Faculty Management
- Department Management
- Course Management
- Enrollment Management
- Moodle Integration
- Synchronization Engine
- Authentication & Authorization
- Reports & Audit Logs
